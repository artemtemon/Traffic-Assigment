В работе рассматривается статическая задача распределения транс- портных потоков (Traffic Assignment Problem) в постановке пользовательского равно- весия Уордропа. Показано её представление в виде выпуклой задачи оптимизации по формуле Бекмана и в седловой форме через лагранжиан с узловыми потенциалами. Обсуждаются условия существования и единственности решения, а также критерии остановки, основанные на UE-gap и duality gap. На этой теоретической базе реализо- ваны два классических алгоритма назначения потоков: алгоритм Франка–Вульфа и метод последовательных усреднений (MSA). Оба метода построены как итеративные схемы «поиск кратчайших путей + обновление потоков» с использованием алгорит- мов кратчайших путей и средств векторизации (JAX). На примере тестовой сети Sioux Falls проведено численное сравнение поведения Франка–Вульфа и MSA по скорости сходимости, числу итераций и вычислительным затратам. Результаты вычислитель- ных экспериментов демонстрируют применимость обоих подходов для поиска поль- зовательского равновесия и выявляют их особенности с точки зрения практической реализации.
